# Alcon — тренировочный вариант

Начинайте с receipt.csv из этой папки. Здесь 117 чеков и ровно 173 отобранные товарные позиции: 121 not null и 52 null. Большой receipt.csv из основного проекта содержит другую выборку (524 позиции) и для этой тренировки не подходит.

## Порядок работы
1. Откройте 1. qual.ipynb в этой папке и выполните все ячейки. Результат появится в «Отчет по нейросети»: result_not_null.xlsx и result_null.xlsx.
2. Перенесите данные обоих файлов в пустой лист data книги «Отчет по нейросети/stats result.xlsx». Столбец raw_json соответствует raw json в шаблоне. Сохраните все 173 строки, исходные поля и повторяющиеся позиции.
3. Заполните corr sku, value и comment. Список SKU и типы комментариев есть в шаблоне. Справочники «Каталог Очкарик» и sku_price_qty доступны в дополнительных материалах основного проекта.
4. В Errors.xlsx перенесите строки с value 1_0 и 0_0: started_at, uuid, name, sku (prediction), corr sku. Если ошибок нет, оставьте заголовки без данных.
5. Откройте дисциплину → Контрольные → Тренировка и загрузите оба XLSX. Получите результат, исправьте замечания и повторите проверку. Тренировочный балл не входит в ведомость.

## Правила разметки
- 1_1: ответ дан и верен; corr sku совпадает с предсказанием, comment пустой.
- 1_0: ответ дан, но неверен; corr sku исправлен, comment «неправильно распознали sku».
- 0_1: пустой ответ корректен; corr sku и comment пустые, кроме отключённых каналов.
- 0_0: пустой ответ ошибочен; corr sku заполнен, comment «не распознали sku».
- Отключённые каналы (Интернет Решения / маркетплейсы, Wildberries, Яндекс): corr sku пустой, value 0_1, comment «не проходит через нейросеть (отключено)». В учебном эталоне это исключение действует и для шести позиций с заполненным предсказанием.
- Для неопределённого размера упаковки применяйте минимальную упаковку из каталога. Правила проекта и справочники остаются основными источниками.
- Сохраняйте маркеры как текст с подчёркиванием: 0_1, а не 01. Пустой SKU не заменяйте числом 0. Для правильных обычных строк оставляйте comment пустым. Пробелы, регистр и ё/е в типе комментария не влияют на результат.

## Баллы
Верная строка: правильны все три поля corr sku, value и comment, а исходные данные не изменены. Балл = 10 × число верных строк / 173, округление до сотых. Перестановка строк допустима. Пропуски не дают баллов, лишние копии не увеличивают результат. Файл Errors проверяется отдельно, без повторного штрафа. Некорректный формат книги возвращается на исправление и не превращается в нулевую оценку.

## Рабочая среда и дополнительные этапы
Среду можно подготовить заранее: Python, Jupyter, зависимости из requirements.txt. Веб-рабочая среда позволяет готовить и хранить файлы; доступность запуска зависит от выбранной среды исполнения.
Скрипт 2 подготавливает stats_for_BI_tmp.xlsx: выделяет дату из started_at, сохраняет исходный комментарий в comment_, добавляет свободный comment. Путь к Stats Result исправлен в учебной копии.
Скрипты 3 и 4 — дополнительные заготовки с требованиями внутри. Баллы за них пока не обещаны. Для основного задания нужны только первый скрипт и два итоговых Excel-файла.
